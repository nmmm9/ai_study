# Database

이 폴더는 week14 챗봇의 데이터 저장소입니다.

## 파일

| 파일 | 설명 |
|------|------|
| `sessions.json` | 멀티세션 대화 기록 (자동 생성) |

## 정책 원본 데이터 위치

실제 청년정책 문서(623개 .md 파일)는 week11에서 API로 수집한 것을 공유 사용합니다:

```
week11-multi-agent/minseon/data/
├── youth_policies/   ← 직접 작성한 주요 정책 (5개)
├── scholarships/     ← 직접 작성한 장학금 (5개)
└── youthcenter/      ← 온통청년 API 수집 (613개)
```
