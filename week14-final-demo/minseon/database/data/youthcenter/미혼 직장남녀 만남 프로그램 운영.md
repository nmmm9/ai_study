# 미혼 직장남녀 만남 프로그램 운영

## 개요

## 지원 내용
○ 사업기간 : '26. 하반기(초가을 경)
  ○ 지원대상 : 울산시에 주민등록을 두거나, 관내 기업에 재직중인 청년
       ※ ('25년) 25~39세  ('26년) 세부계획 수립시, 연령대 확대 가능
  ○ 지원인원 : 남녀 80명 정도 
  ○ 지원방법 : 공개모집(울산시 직접 접수), 시 홈페이지 신청(네이버폼 활용)
  ○ 지원내용 : 바쁜 직장생활로 이성을 만날 기회를 만들지 못한 미혼남녀에게 만남과 이야기 장을 제공
     - 연애코칭, 커플매칭 프로그램, 선상데이트 등
  ○ 수행기관 : 울산광역시 / 입찰 용역 예정
