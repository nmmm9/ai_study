# 전주시 산하기관 채용정보 모아-JOB 운영

## 개요
취업에 어려움을 겪는 청년들에게 시 산하 기관(부서)의 채용계획을 통합 제공하여 채용 정보를 한눈에 볼 수 있도록 정보 접근성 강화

## 지원 내용
-대상 : 공공부문 채용정보를 제공받고 싶어하는 청년
-규모 : 전주시 산하기관(부서)  *출연, 민간위탁기관 포함
-내용 : 청정지대 내 공공일자리 채용계획 통합 게시(월 1회)

## 신청 자격
- 연령: 만 18세 ~ 39세
- 지역: 전북특별자치도 전주시 완산구,전북특별자치도 전주시 덕진구
