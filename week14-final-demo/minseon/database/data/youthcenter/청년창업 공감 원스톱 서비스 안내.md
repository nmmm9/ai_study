# 청년창업 공감 원스톱 서비스 안내

## 개요
청년창업 정책을 한곳에 모아 통합 제공

## 지원 내용
ㅇ (대상) 18~39세 
ㅇ (주요내용) 청년 창업 지원 사업을 한 페이지에 4개 분야로 구현하여 안내

## 신청 자격
- 연령: 만 18세 ~ 39세
- 지역: 경기도 용인시 처인구,경기도 용인시 기흥구,경기도 용인시 수지구
