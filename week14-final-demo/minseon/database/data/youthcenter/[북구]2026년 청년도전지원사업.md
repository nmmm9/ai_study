# [북구]2026년 청년도전지원사업

## 개요
구직단념청년 등을 대상으로 맞춤형 프로그램을 제공하여 청년의 구직의욕 고취, 노동시장 참여 및 취업 촉진 지원

## 지원 내용
○ 도전프로그램(단기) : 5주, 40시간, 참여수당 50만원 지급

○ 도전+ 프로그램(중장기)
-(공통사항) 이수 인센티브 20만원 / 이수 후 6개월 내 취업 후 3개월 근무 시 50만원 추가 지급
- 중기(15주, 120시간) / 참여수당 150만원 지급(50만원*3개월)
- 장기(25주, 200시간) / 참여수당 250만원 지급(50만원*5개월) / 취업관련 활동 시 인센티브 30만원

## 신청 자격
- 연령: 만 18세 ~ 34세
- 지역: 광주시청 동구,광주시청 서구,광주시청 남구,광주시청 북구,광주시청 광산구


## 신청 방법
○ 신청방법 : 고용24 홈페이지 온라인 신청

## 신청 기간
0 ~ 0

## 주관 기관
광주시청
