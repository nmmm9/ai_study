# 울산형 공공예식장 지원사업

## 개요
예비부부에게 합리적이고 부담 없는 결혼 기회 제공 및 지역 맞춤형 결혼 지원 정책으로 청년 정주여건 개선

## 지원 내용
○ 사업기간 : '26. 3. ~ 11.
  ○ 지원대상 : 울산에 주민등록을 둔 예비부부(둘 중 한명만 등록시에도 가능)
  ○ 지원금액 : 예비부부 1쌍당 5백만원
  ○ 지원인원 : 20쌍
  ○ 지원방법 : 공개모집(울산시 직접 접수), 시 홈페이지 신청(네이버폼 활용)
  ○ 지원내용 
    - 공공예식장 대관 : 태화강국가정원(2개소), 울산대공원(3개소), 대왕암공원(1개소), 공공시설(박물관 강당, 가족문화센터 공공예식장, 지관서가 세미나홀)
    - 웨딩패키지(장소꾸밈·예복·메이크업 등) 비용 일부지원
  ○ 수행기관 : 울산광역시 / 입찰 용역 예정

## 신청 자격
- 연령: 만 0세 ~ 99999세
- 지역: 울산광역시 중구,울산광역시 남구,울산광역시 동구,울산광역시 북구,울산광역시 울주군
