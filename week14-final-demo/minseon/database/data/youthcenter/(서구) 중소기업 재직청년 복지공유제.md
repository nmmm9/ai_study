# (서구) 중소기업 재직청년 복지공유제

## 개요
중소기업 재직청년 대상 대기업, 유관기관 공유가능 자원 연계 제공

## 지원 내용
○ 청라 해변공원 캠핑장 이용권 14개 지원(추첨)
    - 오토캠핑장 6면  /  텐트카라반 5면  /  캠핑카라반 3면
