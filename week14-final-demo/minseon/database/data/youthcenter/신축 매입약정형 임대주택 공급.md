# 신축 매입약정형 임대주택 공급

## 개요
무주택 청년들에게 신축 약정형 매입임대주택을 공급하여 공공주택을 신속하게 확보하고 주거비 부담 해소

## 지원 내용
○ 사업기간 : ′26 ~′28년
  ○ 사업규모 : 200호(청년형 24~26㎡)
  ○ 사업금액 : 26,000백만원(국10,710 기융11,900 시 3,390), 호당/130백만원
  ○ 사업방식 : 민간사업자가 건축하는 주택을 매입하기 위해 사전약정을 체결하고, 준공 시 매입하여 공급
  ○ 지원대상 : 울산시 거주(예정)하는 19~39세 무주택 청년층

## 신청 자격
- 연령: 만 19세 ~ 39세
- 지역: 울산광역시 중구,울산광역시 남구,울산광역시 동구,울산광역시 북구,울산광역시 울주군
