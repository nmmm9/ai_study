# 청년콘텐츠 우수인재양성

## 개요
프로젝트 기반의 콘텐츠 제작 교육을 통한 창의적인 실무인재 양성

## 지원 내용
○ 청년 콘텐츠 우수인재 양성 콘텐츠 제작 교육(25명)
○ 청년 서포터즈 운영(실무교육 5명)
○ 일자리 네트워킹 개최(1회)

## 신청 자격
- 연령: 만 19세 ~ 39세
- 지역: 인천광역시 중구,인천광역시 동구,인천광역시 미추홀구,인천광역시 연수구,인천광역시 남동구,인천광역시 부평구,인천광역시 계양구,인천광역시 서구,인천광역시 강화군,인천광역시 옹진군
-
