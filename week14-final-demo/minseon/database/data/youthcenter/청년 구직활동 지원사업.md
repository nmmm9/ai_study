# 청년 구직활동 지원사업

## 개요
청년 구직자의 경제적 부담 완화를 위해 어학·자격시험 응시료, 면접 정장 대여료, 면접 증명사진 촬영비 지원

## 지원 내용
어학·자격시험 응시료 10만원 한도 실비 지원, 면접 정장 대여료 7만원 한도 실비 지원 최대 연 2회, 면접 증명사진 촬영비 지원 3만원 한도 실비 지원
면접 정장 대여료, 증명사진 촬영비는 상시 접수(예산 소진 시 마감)
어학·자격시험 응시료는 상반기(5.1.~5.31.), 하반기(10.1.~10.31.) 선착순 접수

## 신청 자격
- 연령: 만 18세 ~ 39세
- 지역: 경상북도 안동시


## 신청 방법
선착순 지원

## 신청 기간
0 ~ 0

## 주관 기관
경상북도 안동시 평생복지국
