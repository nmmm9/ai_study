# 강진품애(愛) 청년 주거비 지원사업

## 개요
강진에 전입한 지 3개월 이상이며 전, 월세 형태로 거주하는 19~45세 무주택 청년(중위소득 60~160%이하)의 주거지원금 지급(최대 월 25만원)

## 지원 내용
1인 가구 월 20만원, 2인 이상 가구 월 25만원 지급
  대출금 1억원 이하, 대출이자 지원
※ 전월세 매월 납부 금액이 20만 원이 안될 시 실제 납부 금액만 지원

## 신청 자격
- 연령: 만 19세 ~ 45세
- 지역: 전라남도 강진군
19~45세 무주택 청년(공공기관 근로자도 신청 가능)

## 신청 방법
- 신청서류 : 홈페이지 공고문 참고(신청서, 구비서류 안내)
- 제출처 : 강진군청 인구정책과 또는 해당 소재지 읍면사무소

## 신청 기간
0 ~ 0

## 주관 기관
전라남도 강진군 인구정책과
