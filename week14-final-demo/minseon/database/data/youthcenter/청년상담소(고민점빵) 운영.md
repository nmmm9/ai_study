# 청년상담소(고민점빵) 운영

## 개요
복잡하고 다양한 청년문제에 대응하고, 유관기관과 연계하여 전문가와 1:1 매칭 상담으로 행복한 삶 영위와 주체적으로 성장할 기회 제공

## 지원 내용
○ 사업기간 : '26. 2. ~ 12. 
  ○ 사업대상 : 울산시 거주 19세~39세 청년
  ○ 주요사업 : 청년들의 고민을 분야별로 파악하여 전문가와 1:1매칭 상담
  ○ 사업내용 : 마음건강 진단, 상담, 모니터링 등 심리안정 지원
  ○ 수행기관 : 울산청년지원센터

## 신청 자격
- 연령: 만 19세 ~ 39세
- 지역: 울산광역시 중구,울산광역시 남구,울산광역시 동구,울산광역시 북구,울산광역시 울주군
