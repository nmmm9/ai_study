# (광양시)청년 주택자금 대출이자 지원사업

## 개요
무주택 청년의 주택 구입·전세자금 대출이자 일부를 지원해 주거비 부담을 완화하는 사업입니다.

## 지원 내용
-주택 구입 대출이자 최대 3% 지원(연 최대 300만원)
-전세(임대) 대출이자 최대 3% 지원(연 최대 200만원)
-최장 구입 10년·전세 8년 지원

## 신청 자격
- 연령: 만 19세 ~ 45세
- 지역: 전라남도 광양시
