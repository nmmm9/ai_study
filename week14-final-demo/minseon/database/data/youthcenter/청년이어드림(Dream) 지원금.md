# 청년이어드림(Dream) 지원금

## 개요
- 청년들의 정책 참여를 높여 제주형 청년보장제의 빈 공간을 채우는 청년 맞춤형 정책 전달체계
  - (오프라인)
    청년과 정책을 이어주는 1:1 맞춤형 정책 상담 / 1~3단계 운영, 각 단계별 참여시 지원금 지급
  - (온라인)
    청년정책 및 청년소식 전달 제주청년플랫폼 운영

## 지원 내용
청년이어드림 지원사업의 단계별 참여((1단계)정책상담 - (2단계)정책참여 - (3단계)피드백상담)를 완료한 경우 지원금(지역화폐) 지급 
- 정책참여 10~60만원 / 정책미참여 10~40만원

## 신청 자격
- 연령: 만 19세 ~ 39세
- 지역: 제주특별자치도 제주시


## 신청 방법
- 청년이어드림 플랫폼을 통한 신청
- 회원가입 후 상담 오픈일에 맞춰 선착순 신청
- 상담오픈일 공지사항 별도 공지

## 신청 기간
0 ~ 0

## 주관 기관
제주청년센터
