# 그린스타트업타운 운영

## 개요
신성장·친환경·ICT 분야 스타트업 발굴/육성사업

## 지원 내용
스타트업 대상 입주공간, 경영컨설팅, 기술사업화, 글로벌 진출지원, 청년인재 정주여건, 스타트업 직무교육지원 등

## 신청 자격
- 연령: 만 0세 ~ 99999세
- 지역: 충청남도 천안시,충청남도 공주시,충청남도 보령시,충청남도 아산시,충청남도 논산시,충청남도 계룡시,충청남도 당진시,충청남도 금산군,충청남도 부여군,충청남도 서천군,충청남도 청양군,충청남도 홍성군,충청남도 예산군,충청남도 태안군
그린스타트업타운 입주 후 지원사업 신청 가능

## 신청 방법
사업별 모집공고 확인 → 신청/접수 → 선정평가 → 최종선정 대상자별 협약체결 후 지원

## 신청 기간
0 ~ 0

## 주관 기관
