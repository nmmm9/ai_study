# 대학생 봉사활동 활성화

## 개요
청년들을 대상으로 자원봉사활동을 지원하여 이타심과 공동체성을 배양하고 더불어 사는 지역사회 조성에 기여

## 지원 내용
○ 사업기간 : `26. 1. ~ 12.
  ○ 지원대상 : 대학생봉사단(`26년 21기 봉사단)
  ○ 지원방법 : 시 자원봉사센터 '대학생 봉사활동 활성화' 사업비 지원
  ○ 수행기관 : (사)울산광역시자원봉사센터
