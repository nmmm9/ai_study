# 시 공공기관 청년인턴 채용사업

## 개요
공공부문 중심의 양질의 일자리 제공으로 청년 취업난을 해소하고, 직업체험을 통한 청년 취업역량 강화

## 지원 내용
○ 사업기간 : '26. 4. ~ 12.  ※ 기관별 3~6개월 채용

  ○ 대    상 : 울산에 주민등록을 둔 15세~34세 미취업 청년
  ○ 지원금액 : 1인 월 1,980천원(인건비에 한함)
  ○ 채용기관/인원 : 울산연구원 등 8개 기관 / 99명
    ※ (시비 및 자부담) 7개 기관 65명 / (자부담) 1개 기관 34명
  ○ 운영방법 : 기관별 직무와 예산상황 등 감안 자율적 채용‧운영

## 신청 자격
- 연령: 만 15세 ~ 34세
- 지역: 울산광역시 중구,울산광역시 남구,울산광역시 동구,울산광역시 북구,울산광역시 울주군
