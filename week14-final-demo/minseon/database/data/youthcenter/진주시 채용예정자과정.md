# 진주시 채용예정자과정

## 개요
진주시 청년일자리 지원을 위한 청년들의 취업역량 강화 도모

## 지원 내용
○ 신청기간 : 연중 수시
○ 지원대상 : 진주시 거주하는 항공부품 제조분야 생산직 취업을 희망하는 18 ~ 39세 청년구직자
○ 교육과정 : 항공산업 특화 항공기체조립 기술자 양성
○ 교육시간 : 매주 월~금 23일 ( 7시간/일, 9:00~17:00)
○ 지원내용 : 교육비, 교재, 중식, 훈련수당 30만원(국비 20만원 별도), 취업장려금 50만원

## 신청 자격
- 연령: 만 18세 ~ 39세
- 지역: 경상남도 진주시


## 신청 방법
□ 신청절차 : 온라인 접수(응시원서 제출) → 채용예정업체 면접 → 훈련생 확정(교육훈련) → 수료 후  취업

## 신청 기간
0 ~ 0

## 주관 기관
경상남도 진주시 인구청년정책관
