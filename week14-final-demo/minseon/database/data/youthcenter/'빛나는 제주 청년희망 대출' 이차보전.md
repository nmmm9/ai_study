# '빛나는 제주 청년희망 대출' 이차보전

## 개요
제주도 내 청년층의 실질적 금융부담 경감을 위해 NH농협은행 제주본부와 협약하여 융자 지원을 통한 청년 맞춤형 저금리 대출 실행

## 지원 내용
ㅇ지원대상: 연소득 4,500만원 이하, 재직기간 1개월 이상의 도내 근로소득 청년(만19~39세)
ㅇ대출한도: 신규대출 1,000만원, 대환대출 2,500만원(단, 기존대출 잔액 이내)
ㅇ지원내용: 대출금리의 이자차액 보전  *보전금리: 1~3신용등급 3%, 4~9신용등급 4%

## 신청 자격
- 연령: 만 19세 ~ 39세
- 지역: 제주특별자치도 제주시,제주특별자치도 서귀포시


## 신청 방법
NH농협은행 제주본부 또는 지점 방문하여 대출가능 여부 상담 후 융자지원 신청

## 신청 기간
0 ~ 0

## 주관 기관
제주특별자치도 경제활력국 경제정책과
