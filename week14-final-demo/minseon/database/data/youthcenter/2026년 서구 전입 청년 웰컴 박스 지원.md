# 2026년 서구 전입 청년 웰컴 박스 지원

## 개요
서구 전입 청년 1인 가구의 초기 정착을 지원하고 청년 정책 참여 활성화

## 지원 내용
생활 물품과 청년 정책 책자로 구성된 웰컴 박스 제공

## 신청 자격
- 연령: 만 19세 ~ 39세
- 지역: 광주시청 서구


## 신청 방법
신청접수(온·오프라인) → 신청서류 확인 → 확정 통보 → 물품 수령

## 신청 기간
0 ~ 0

## 주관 기관
