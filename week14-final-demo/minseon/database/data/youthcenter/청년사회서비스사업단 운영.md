# 청년사회서비스사업단 운영

## 개요
청년이 주체가 되어 지역사회서비스를 개발·제공함으로써 청년의 사회활동 참여기회를 보장하고 지역주민 삶의 질 향상

## 지원 내용
○ 사업기간 : '26. 1. ~ 12.
  ○ 사업내용 : 청년사업단이 청년(19-~39세) 채용해 사회서비스 제공
    - 일상돌봄 서비스 사업, 초등돌봄, 청년 신체건강증진 등
  ○ 수행기관 : 공모중('26. 2월 중 선정)

## 신청 자격
- 연령: 만 19세 ~ 39세
