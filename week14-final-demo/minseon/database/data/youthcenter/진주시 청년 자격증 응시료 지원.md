# 진주시 청년 자격증 응시료 지원

## 개요
미취업 청년 자격증 응시료 지원

## 지원 내용
- 지원대상 : 진주시 주민등록을 둔 18세~39세 미취업 청년 
- 지원기간 : 2026. 2. ~ 예산 소진 시
- 지원내용 : 한국사, 어학, 국가기술자격시험 응시료 실비 지원 ※ 1인 연 2회, 연 10만원 한도
- 신청방법 : 진주시 청년 온라인 플랫폼

## 신청 자격
- 연령: 만 18세 ~ 39세
- 지역: 경상남도 진주시
신청일 기준 미취업자

## 신청 방법
온라인 신청(진주시청년온라인플랫폼) - 담당자 검토(승인 및 반려) - 계좌입금(익월 15일 이내)

## 신청 기간
0 ~ 0

## 주관 기관
경상남도 진주시 인구청년정책관
