# 산모건강회복비 지원사업

## 개요
출산산모의 경제적 부담을 경감하여 출산 친화적인 분위기 조성

## 지원 대상
- 지역: 전남광주통합특별시 고흥군
- 생애주기: 임신 · 출산, 청년
- 대상 특성: 
- 관심 주제: 임신·출산, 서민금융

## 신청 자격
출산일 현재 고흥군 거주 산모

## 지원 내용
지원대상 : 출산일 현재 고흥군에 주소를 두고 실제 거주한 모든 산모지원내용 : 관내산부인과 분만자 : 첫째아 200만원 / 둘째아 이상 : 220만원              기초(생계,의료)수급가정 : 첫째아 200만원 / 둘째아 이상 : 220만원              차상위가정 : 첫째아 150만원 / 둘째아 이상 : 170만원              장애등록 산모가정 : 첫째아 100만원 / 둘째아 이상 : 120만원              일반 출산가정 : 첫째아 50만원 / 둘째아 이상 : 70만원

## 신청 방법
행복출산통합서비스 신청

## 소관 기관
전남광주통합특별시 고흥군 보건소
